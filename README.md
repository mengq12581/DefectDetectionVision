# VisionDemo2026

`VisionDemo2026` 是一个基于 **C# WinForms + HALCON** 开发的**圆环零件缺陷检测**上位机。项目使用传统机器视觉方法完成图像采集、预处理、区域分割、几何特征提取、OK/NG 判定、结果标注和报告导出。

项目既可读取本地单张图片或图片文件夹，也可通过USB 摄像头或 GigE 工业相机采集图像，适合用于 HALCON 二次开发、WinForms 视觉软件和缺陷检测流程学习。

## 主要功能

### 图像输入与采集

- 打开单张图片并自动检测；单图模式下“上一张”和“下一张”按钮自动禁用。
- 打开图片文件夹，按文件名排序加载，并支持上一张、下一张循环切换。
- 自动保存最近一次打开的单图或文件夹路径，下次启动时按原来源类型恢复。
- 支持 `MediaFoundation` 接口，可使用笔记本内置摄像头或普通 USB 摄像头做连接测试。
- 支持 `GigEVision2` 接口，可搜索和打开 GigE Vision 工业相机。
- 支持相机搜索、设备选择、曝光设置、单次采集、连续采集和停止采集。
- 单次采集后立即检测；连续采集时实时预览，停止后检测最后一帧。
- 自动保存相机接口、显示名称、HALCON 原始设备标识和曝光值。

### 图像处理与检测

- 亮度和对比度调整。
- CLAHE 局部对比度增强。
- 高斯滤波去噪。
- 手动阈值、Otsu 自动阈值和自适应阈值三种分割模式。
- 开运算去除小噪点，闭运算连接小间隙。
- Canny 边缘提取。
- 连通域分析与固定候选面积筛选。
- 矩形 ROI 交互绘制和局部检测。
- 提取面积、周长、中心坐标、外接矩形、圆度、实心度、填充率、内孔数量和旋转无关的长宽比。
- 对内、外圈按角度统计局部半径，检测未贯穿的小缺口。
- 根据面积、实心度、圆度、内孔数量、长宽比和局部缺口进行综合 OK/NG 判定，并在报告中记录 NG 原因。

### 显示与输出

- 使用 HALCON `HWindowControl` 按原图比例显示，避免图像拉伸变形。
- 分页显示检测标注图、二值 Mask 图和 Canny 边缘图。
- 合格零件使用绿色标注，缺陷零件使用红色标注，ROI 使用黄色标注。
- 标注文字直接使用中文显示面积、实心度和圆度。
- 导出带标注结果图、Mask 图及中文文本检测报告。

## 快速开始

1. 使用 Visual Studio 2022 打开 `VisionDemo2026.sln`。
2. 检查项目中的 `halcondotnet.dll` 引用路径是否指向本机 HALCON 安装目录。
3. 将解决方案平台设置为 `x64`。
4. 生成并运行项目。
5. 选择“打开图片”“打开图片文件夹”或使用右上角相机采集区获取图像。
6. 图像加载或单次采集后程序会自动检测；也可以修改参数或单击“开始检测”重新检测。
7. 需要限制检测范围时，单击“绘制 ROI”并在图像窗口拖动矩形；单击“重置 ROI”恢复整图检测。
8. 检测完成后单击“导出检测报告”保存结果。

## 相机使用

### 本地摄像头

1. 在“相机接口”中选择 `本地相机`，对应 HALCON `MediaFoundation` 接口。
2. 单击“搜索相机”。
3. 在相机下拉框中选择笔记本内置摄像头或 USB 摄像头。
4. 使用“单次采集”获取一帧并检测，或使用“连续采集”进行预览。
5. 连续预览结束时单击“停止采集”，程序会检测保存的最后一帧。

若未搜索到设备，请检查 Windows 的相机隐私权限，并确认没有其他程序独占摄像头。

### GigE 工业相机

1. 在“相机接口”中选择 `网络相机`，对应 HALCON `GigEVision2` 接口。
2. 确认相机网卡、IP 地址和 HALCON GigEVision2 接口已经正确配置。
3. 单击“搜索相机”并选择设备。
4. 根据相机参数范围填写曝光值后采集图像。

不同相机接口和厂商的曝光参数名称、单位及有效范围可能不同。Helper 会依次尝试 MediaFoundation 和常见 GenICam 曝光参数；设备不支持时会显示中文提示。

## 检测流程

```text
本地图像 / 相机图像
  -> 亮度与对比度调整
  -> 灰度化
  -> CLAHE 局部增强（可选）
  -> 高斯滤波
  -> 手动 / Otsu / 自适应阈值分割
  -> 开运算与闭运算
  -> ROI 区域限制（可选）
  -> 连通域分析
  -> 候选面积筛选（固定 1000~8000）
  -> 面积、实心度、圆度、内孔数量、旋转长宽比、内外圈局部半径等特征提取
  -> 综合合格范围判定
  -> 结果标注、统计与报告导出
```

候选目标面积 `1000~8000` 写在检测 Helper 中，只用于排除小噪点和大面积背景。界面中的面积参数表示产品的合格范围，不会改变候选目标搜索范围。

`Canny` 边缘图由高斯滤波后的灰度图单独生成，用于边缘页签观察和调参；它当前不参与候选区域生成，也不直接参与 OK/NG 判定。

## 默认判定规则

| 特征 | 默认合格范围 | 说明 |
| --- | --- | --- |
| 面积 | 4000~5500 | 小于最小值或大于最大值均为 NG |
| 实心度 | 80%~90% | 不在闭区间内判定为 NG |
| 圆度 | 不低于界面设定值 | 低于下限判定为 NG |
| 内孔数量 | 必须为 1 | 贯穿裂缝或断裂会使圆环失去闭合内孔 |
| 长宽比 | 不高于界面设定值 | 使用旋转最小外接矩形识别椭圆变形 |
| 内、外圈局部缺口 | 固定规则：局部半径偏差不低于 2 px，且连续异常覆盖 3~30 个角度扇区 | 外圈局部半径变小或内圈局部半径变大时判定为 NG |

面积、实心度、圆度、内孔数量和长宽比必须同时满足要求，零件才判定为 OK。对内孔完整且整体形状正常的圆环，还会继续检查局部缺口；任一指标不合格即判定为 NG。

### 判定逻辑

程序先通过阈值分割、形态学处理和连通域分析得到候选零件，再以固定面积 `1000~8000` 排除明显小噪点和大面积背景。候选区域不会因为不满足产品合格范围而被丢弃，而是继续计算特征并标记为 NG，便于显示和导出。

| 判定特征 | 计算方式 | NG 条件 | 主要筛选目的 |
| --- | --- | --- | --- |
| 面积 | 区域像素总数 | 小于合格最小面积或大于合格最大面积 | 缺料、多料、整体尺寸异常 |
| 实心度 | HALCON `Convexity` | 不在设定的最小/最大范围内 | 明显凹陷、轮廓不完整 |
| 圆度 | HALCON `Circularity` | 低于圆度下限 | 非圆形、局部轮廓异常 |
| 内孔数量 | HALCON `ConnectAndHoles` | 不等于 `1` | 贯穿裂缝、断裂、孔缺失或额外孔洞 |
| 长宽比 | 旋转最小外接矩形的长轴/短轴 | 高于最大长宽比 | 椭圆变形、拉伸变形；与零件旋转角度无关 |
| 外圈缺口 | 将闭运算前的候选区域按 180 个角度扇区统计最外半径，并与中位半径比较 | 局部半径向内缩小至少 2 px，且连续异常扇区为 3~30 个 | 外圈崩边、非贯穿小缺口 |
| 内圈缺口 | 在相同角度扇区统计最内半径，并与中位半径比较 | 局部半径向外扩大至少 2 px，且连续异常扇区为 3~30 个 | 内孔边缘缺口、内圈局部缺料 |

局部缺口检测使用开运算后的区域，而非闭运算后的区域，避免闭运算填补小缺口；闭运算后的区域仍用于稳定定位零件。局部缺口阈值为代码内固定值，没有放入窗体界面。程序会在结果报告中写出“外圈缺口”或“内圈缺口”，并记录相应深度。

### 可筛选的圆环缺陷

| 缺陷类型 | 当前规则如何识别 |
| --- | --- |
| 贯穿裂缝、断裂 | 裂缝从外圆连通到内孔后，闭合内孔消失，内孔数量由 `1` 变为 `0` |
| 外圈非贯穿小缺口 | 外圈局部半径相对中位半径明显减小，输出“外圈缺口” |
| 内圈非贯穿小缺口 | 内圈局部半径相对中位半径明显增大，输出“内圈缺口” |
| 椭圆、拉伸等整体变形 | 旋转长宽比增大，通常同时伴随圆度下降 |
| 明显缺料、崩边、轮廓凹陷 | 面积减少，实心度和圆度可能下降 |
| 多料、粘连或轮廓凸出 | 面积增大，圆度、实心度或长宽比异常 |
| 孔缺失或额外孔洞 | 内孔数量不再等于 `1` |

### 当前边界

该项目适合筛选轮廓和拓扑结构发生明显变化的圆环缺陷，新增规则可覆盖深度不低于约 2 px 的内、外圈非贯穿缺口。小于该像素尺度的缺口、表面划痕、污渍、颜色差异，以及不改变二值轮廓的微小缺陷，仍可能漏检。要覆盖这类缺陷，需要在环形 ROI 内补充局部灰度差分、边缘连续性、模板比对或深度学习检测。

## 参数说明

| 参数 | 作用 |
| --- | --- |
| 亮度 | 调整图像整体明暗，50 为默认基准值 |
| 对比度 | 调整前景与背景灰度差异，50 为默认基准值 |
| 局部对比度增强 | 使用 HALCON CLAHE 增强局部细节 |
| 高斯滤波等级 | 控制平滑强度，等级越大滤波核越大 |
| 阈值模式 | 选择手动、Otsu 自动或自适应阈值 |
| 手动阈值 | 仅在手动阈值模式下使用 |
| 自适应块等级 | 控制动态阈值背景估计窗口 |
| 开运算半径 | 去除孤立小区域和小噪点 |
| 闭运算半径 | 连接小间隙并平滑目标区域 |
| Canny 低阈值 | 控制边缘检测灵敏度 |
| 合格最小/最大面积 | 设置产品面积合格范围 |
| 最小/最大实心度 | 设置产品实心度合格范围 |
| 圆度下限 | 设置产品允许的最低圆度 |
| 最大长宽比 | 设置零件允许的最大椭圆变形程度，135% 表示长轴不超过短轴的 1.35 倍 |

## 样例图

项目内置 8 张静态检测样例，默认输出位置为：

```text
VisionDemo2026\SampleImages
```

每张图片包含 15~20 个完整、互不叠放的圆环零件，并带有少量小噪点。样例分为四类：

- 合格圆环：面积、实心度和圆度基本一致。
- 裂缝或断裂件：整体外接矩形与合格件相近，但环体存在裂缝或断口。
- 变形件：轮廓发生拉伸或扭曲，不再保持正常圆环形状。
- 内外圈非贯穿缺口件：整体尺寸和内孔数量与合格圆环保持一致，仅在内圈或外圈制造局部小缺口。

`sample_manifest.csv` 保存每个样例零件的类别和中心坐标。程序不会在用户未加载图像时临时生成模拟图。

需要重新生成同一批样例时，在解决方案目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Tools\Generate-SampleImages.ps1
```

脚本默认使用固定随机种子，也可以通过 `-Seed` 参数生成另一组符合相同约束的样例。

## 配置与输出

程序运行后会在可执行文件目录创建以下内容：

```text
Config\LastImageSource.json   # 最近一次单图或文件夹来源
Config\CameraConfig.json     # 相机接口、设备标识和曝光配置
reports\                     # 导出的检测结果
```

报告目录包含：

- `*_result.png`：包含 OK/NG、中文特征文字和 ROI 的标注结果图。
- `*_mask.png`：阈值分割和形态学处理后的二值 Mask 图。
- `*_report.txt`：检测概况、检测参数和每个零件的中文字段明细。

单图配置会恢复指定图片，并保持导航按钮禁用；文件夹配置会重新扫描目录、按名称排序并从第一张开始。路径失效时程序会提示用户重新选择。

## 注意事项

- 默认检测参数针对内置样例图调整。真实图像的分辨率、光照、背景和零件尺寸变化后，需要重新调整分割及合格范围。
- 当前算法属于基于区域几何特征的传统规则检测，适用于圆环断裂、缺口和明显变形，不适合直接处理复杂纹理或未知类别缺陷。
- 相机连续采集通过 UI 线程更新图像；停止采集或关闭窗体时会统一释放采集句柄、`HImage` 和 `HObject` 资源。
- 后续可以在现有 Helper 基础上扩展形状模板匹配、计量模型、标定、深度学习分类、异常检测或机器人通讯。
