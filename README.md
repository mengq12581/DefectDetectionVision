# VisionDemo2026

`VisionDemo2026` 是一个基于 **C# WinForms + HALCON** 开发的**圆环零件缺陷检测**上位机。项目使用传统机器视觉方法完成图像采集、预处理、区域分割、几何特征提取、OK/NG 判定、结果标注和报告导出。

项目支持本地单张图片、图片文件夹离线检测及 GigE Vision 工业相机采集，适合用于 HALCON 二次开发、WinForms 视觉软件和缺陷检测流程学习。

本仓库只提交源代码、项目文件、样例图和生成脚本，不包含 HALCON 安装包、HALCON 授权文件、相机驱动、NuGet 本地缓存和编译输出。

## 主要功能

### 图像输入与采集

- 打开单张图片并自动检测；单图模式下“上一张”和“下一张”按钮自动禁用。
- 打开图片文件夹，按文件名排序加载，并支持上一张、下一张循环切换。
- 自动保存最近一次打开的单图或文件夹路径，下次启动时按原来源类型恢复。
- 支持 `GigEVision2` 接口，可搜索和打开 GigE Vision 工业相机。
- 支持相机搜索、设备选择、曝光设置、单次采集、连续采集和停止采集。
- 单次采集后立即检测；连续采集时实时预览，停止后检测最后一帧。
- 自动保存相机接口、显示名称、HALCON 原始设备标识和曝光值。

### 图像处理与检测

- 亮度和对比度调整。
- CLAHE 局部对比度增强。
- 高斯滤波去噪。
- 手动阈值、Otsu 自动阈值和自适应阈值三种分割模式。
- 开运算去除小噪点，闭运算连接小间隙。
- Canny 边缘提取。
- 连通域分析与固定候选面积筛选。
- 矩形 ROI 交互绘制和局部检测。
- 提取面积、周长、中心坐标、外接矩形、圆度、实心度、填充率和长宽比。
- 根据面积、实心度和圆度范围进行 OK/NG 判定。

### 显示与输出

- 使用 HALCON `HWindowControl` 按原图比例显示，避免图像拉伸变形。
- 分页显示检测标注图、二值 Mask 图和 Canny 边缘图。
- 合格零件使用绿色标注，缺陷零件使用红色标注，ROI 使用黄色标注。
- 标注文字直接使用中文显示面积、实心度和圆度。
- 导出带标注结果图、Mask 图及中文文本检测报告。

## 运行环境

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / Windows 11 64 位 |
| 开发环境 | Visual Studio 2022 |
| 运行框架 | .NET Framework 4.7.2 |
| 视觉库 | HALCON 24.05 64 位 |
| 界面库 | SunnyUI 3.9.8 |
| 解决方案平台 | x64 |
| 工业相机接口 | HALCON GigEVision2 |

HALCON、项目目标平台和相机采集接口必须保持相同位数。工程当前按 `x64` 配置。

## 快速开始

1. 使用 Visual Studio 2022 打开 `VisionDemo2026.sln`。
2. 在 Visual Studio 中执行 NuGet 还原，项目会按 `packages.config` 恢复 SunnyUI 3.9.8。
3. 安装 HALCON 24.05（或兼容版本），并设置项目的 HALCON 引用路径，见下方“HALCON 依赖配置”。
4. 将解决方案平台设置为 `x64`。
5. 生成并运行项目。
6. 选择“打开图片”“打开图片文件夹”或使用右上角相机采集区获取图像。
7. 图像加载或单次采集后程序会自动检测；也可以修改参数或单击“开始检测”重新检测。
8. 需要限制检测范围时，单击“绘制 ROI”并在图像窗口拖动矩形；单击“重置 ROI”恢复整图检测。
9. 检测完成后单击“导出检测报告”保存结果。

### HALCON 依赖配置

项目文件不会写入开发者本机的绝对路径。`halcondotnet.dll` 的查找顺序如下：

1. MSBuild 属性 `HalconDotNetPath`；
2. MSBuild 属性 `HalconRoot` 下的 `bin\dotnet45\halcondotnet.dll` 或 `bin\dotnet35\halcondotnet.dll`；
3. 系统环境变量 `HALCONROOT` 对应的 HALCON 安装目录。

可以在 Visual Studio 的项目属性中设置 `HalconRoot`，也可以在 PowerShell 中执行：

```powershell
$env:HALCONROOT = 'C:\Program Files\MVTec\HALCON-24.05-Progress'
```

或者直接编译时传入 DLL 路径：

```powershell
msbuild .\VisionDemo2026.sln /p:Configuration=Debug /p:Platform=AnyCPU /p:HalconDotNetPath='C:\路径\halcondotnet.dll'
```

实际安装目录和 HALCON 版本可能不同，请按本机安装位置调整。

## 相机使用

### GigE 工业相机

1. 在“相机接口”中选择 `网络相机`，对应 HALCON `GigEVision2` 接口。
2. 确认相机网卡、IP 地址和 HALCON GigEVision2 接口已经正确配置。
3. 单击“搜索相机”并选择设备。
4. 根据相机参数范围填写曝光值后采集图像。

不同工业相机厂商的曝光参数名称、单位及有效范围可能不同。Helper 会依次尝试常见 GenICam 曝光参数；设备不支持时会显示中文提示。

## 检测流程

```text
本地图像 / 相机图像
  -> 亮度与对比度调整
  -> 灰度化
  -> CLAHE 局部增强（可选）
  -> 高斯滤波
  -> 手动 / Otsu / 自适应阈值分割
  -> 开运算与闭运算
  -> ROI 区域限制（可选）
  -> 连通域分析
  -> 候选面积筛选（固定 1000~8000）
  -> 面积、实心度、圆度等特征提取
  -> 合格范围判定
  -> 结果标注、统计与报告导出
```

候选目标面积 `1000~8000` 写在检测 Helper 中，只用于排除小噪点和大面积背景。界面中的面积参数表示产品的合格范围，不会改变候选目标搜索范围。

## 默认判定规则

| 特征 | 默认合格范围 | 说明 |
| --- | --- | --- |
| 面积 | 4000~5500 | 小于最小值或大于最大值均为 NG |
| 实心度 | 80%~90% | 不在闭区间内判定为 NG |
| 圆度 | 不低于界面设定值 | 低于下限判定为 NG |

面积、实心度和圆度必须同时满足要求，零件才判定为 OK。任一指标不合格即判定为 NG。

## 参数说明

| 参数 | 作用 |
| --- | --- |
| 亮度 | 调整图像整体明暗，50 为默认基准值 |
| 对比度 | 调整前景与背景灰度差异，50 为默认基准值 |
| 局部对比度增强 | 使用 HALCON CLAHE 增强局部细节 |
| 高斯滤波等级 | 控制平滑强度，等级越大滤波核越大 |
| 阈值模式 | 选择手动、Otsu 自动或自适应阈值 |
| 手动阈值 | 仅在手动阈值模式下使用 |
| 自适应块等级 | 控制动态阈值背景估计窗口 |
| 开运算半径 | 去除孤立小区域和小噪点 |
| 闭运算半径 | 连接小间隙并平滑目标区域 |
| Canny 低阈值 | 控制边缘检测灵敏度 |
| 合格最小/最大面积 | 设置产品面积合格范围 |
| 最小/最大实心度 | 设置产品实心度合格范围 |
| 圆度下限 | 设置产品允许的最低圆度 |

## 样例图

项目内置 8 张静态检测样例，默认输出位置为：

```text
VisionDemo2026\SampleImages
```

每张图片包含 15~20 个完整、互不叠放的圆环零件，并带有少量小噪点。样例分为三类：

- 合格圆环：面积、实心度和圆度基本一致。
- 裂缝或断裂件：整体外接矩形与合格件相近，但环体存在裂缝或断口。
- 变形件：轮廓发生拉伸或扭曲，不再保持正常圆环形状。

`sample_manifest.csv` 保存每个样例零件的类别和中心坐标。程序不会在用户未加载图像时临时生成模拟图。

需要重新生成同一批样例时，在解决方案目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Tools\Generate-SampleImages.ps1
```

脚本默认使用固定随机种子，也可以通过 `-Seed` 参数生成另一组符合相同约束的样例。

## 配置与输出

程序运行后会在可执行文件目录创建以下内容：

```text
Config\LastImageSource.json   # 最近一次单图或文件夹来源
Config\CameraConfig.json     # 相机接口、设备标识和曝光配置
reports\                     # 导出的检测结果
```

报告目录包含：

- `*_result.png`：包含 OK/NG、中文特征文字和 ROI 的标注结果图。
- `*_mask.png`：阈值分割和形态学处理后的二值 Mask 图。
- `*_report.txt`：检测概况、检测参数和每个零件的中文字段明细。

单图配置会恢复指定图片，并保持导航按钮禁用；文件夹配置会重新扫描目录、按名称排序并从第一张开始。路径失效时程序会提示用户重新选择。

## 注意事项

- 默认检测参数针对内置样例图调整。真实图像的分辨率、光照、背景和零件尺寸变化后，需要重新调整分割及合格范围。
- 当前算法属于基于区域几何特征的传统规则检测，适用于圆环断裂、缺口和明显变形，不适合直接处理复杂纹理或未知类别缺陷。
- 相机连续采集通过 UI 线程更新图像；停止采集或关闭窗体时会统一释放采集句柄、`HImage` 和 `HObject` 资源。
- 后续可以在现有 Helper 基础上扩展形状模板匹配、计量模型、标定、深度学习分类、异常检测或机器人通讯。
